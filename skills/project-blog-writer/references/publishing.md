# 发布与核对

只在用户要求保存、发布或更新现有文章时使用。技能说明不会替用户授权公开内容。

先确认目标网站或仓库、现有文章格式和登录方式。优先使用已有 CMS、连接器或项目发布脚本，保留原站样式与分类。不要为了发文章更换网站框架。

更新文章时用已有 ID 或稳定 slug 定位；重复执行应更新同一篇，避免创建多个副本。媒体尽量保存到目标网站自己的媒体库，减少本地绝对路径或临时外链。Markdown 与 CMS HTML 分开保存，代码块要保留换行和转义，宽表格应能横向滚动。

实际检查列表入口、正文、图片、代码、来源链接和页面窄屏表现。用用户可访问的地址报告结果；本地网站只能说已发布到本地网站，不声称已经公网部署。GitHub 发布需确认远端文件存在，不能仅凭本地 commit 声称成功。

如果发布方式、权限或目标不明确，保留可审阅的草稿，再询问必要信息。不能因为缺少发布权限丢弃已写好的文章。
